# Axodus Marketplace Website

Static institutional product website for Axodus Marketplace.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy with Vercel

1. Add these files to the root of your GitHub repository.
2. Import the repository into Vercel.
3. Keep the detected framework as **Next.js**.
4. Use `npm run build` as the build command.
5. No environment variables are required.

The main live-development CTA points to
[`dev.marketplace.country`](https://dev.marketplace.country).
